# План: локализация (ru/en) + тёмная тема для Web UI

## Цель

В web UI (`web/`) добавить:
1. **Локализацию ru/en** — автоопределение по `navigator.language` + переключатель (Settings + сайдбар).
2. **Тёмную тему** — автоопределение по `prefers-color-scheme` + переключатель (Settings + сайдбар).

Backend не трогаем. Настройки UI — `localStorage` (per-browser).

---

## Ключевые решения

| Решение | Выбор | Почему |
|---|---|---|
| i18n-библиотека | `i18next` + `react-i18next` (≥15 для React 19) | стандарт, user просил «использовать i18n» |
| Менеджер пакетов | **bun** (не npm) | выбор пользователя |
| Тёмная тема | **Свап стилей** `lara-light-indigo` ↔ `lara-dark-indigo` через `<link id="pt-theme">` | в lara-темах ~1000 hardcoded-цветов в компонентных правилах — override CSS-переменных даст «полутёмный» UI |
| Anti-FOUC | Inline-скрипт в `index.html` до paint + стабильные пути `/themes/*.css` в `public/` | hashed Vite-ассеты нельзя узнать в inline-скрипте |
| Привязка prefs | `localStorage`: `rustcache.lang` = `auto\|ru\|en`, `rustcache.theme` = `auto\|light\|dark` | не в config.toml — это per-browser |
| Переключатели | Settings (полные Radio/Dropdown) + сайдбар (цикл кнопками) | выбор пользователя |
| Длинные тексты Connect | Полный перевод, shell-команды остаются как есть | выбор пользователя |

## Структура ключей локалей

Именование — контракт, держать стабильным:

```
app.title
nav.{dashboard,health,requests,exclusions,cache,connect,settings,ca}
common.{refresh,save,cancel,add,copy,copied,download,loading,empty,error,done,warning,ms}
units.bytes.{b,kb,mb,gb}          // "{{n}} Б" / "{{n}} B"
units.time.{sec,min,hour,day}
ui.theme.{label,auto,light,dark,toggle}
ui.lang.{label,auto,ru,en,toggle}
dashboard.*, health.*, requests.*, exclusions.*, cache.*, settings.*, connect.*, ca.*
```

Интерполяция: `{{count}}`, `{{value}}`, `{{ip}}`, `{{n}}` (i18next).
JSX в строках: только через `<Trans i18nKey="..." components={{ 1: <a …/>, 2: <code/> }} />`.
Shell-команды (`netsh`, `export`, `curl`) **не** переводить — остаются в TSX как `<Code>{…}</Code>`.

## Тема — конкретика

1. `scripts/copy-themes.mjs` копирует:
   - `node_modules/primereact/resources/themes/lara-light-indigo/theme.css` → `public/themes/lara-light-indigo.css`
   - то же для `lara-dark-indigo`
2. `index.html` (порядок важен):
   ```html
   <link rel="preload" as="style" href="/themes/lara-light-indigo.css">
   <link rel="preload" as="style" href="/themes/lara-dark-indigo.css">
   <link id="pt-theme" rel="stylesheet" href="/themes/lara-light-indigo.css">
   <script>/* inline: localStorage + matchMedia → set #pt-theme.href, data-theme, html lang */</script>
   ```
3. Runtime `applyTheme(mode)`:
   - `mode==='auto'` → `matchMedia('(prefers-color-scheme: dark)')`
   - `document.documentElement.dataset.theme = 'light'|'dark'`
   - `#pt-theme.href = /themes/lara-${t}-indigo.css`
4. В `auto`-режиме — подписка на `matchMedia` change, unsubscribe на unmount.
5. Chart.js не читает CSS vars — при смене темы ставить `Chart.defaults.color` / `borderColor` из computed style (`--text-color-secondary`, `--surface-border`).

## i18n — конкретика

`i18n/index.ts`:
```ts
supportedLngs: ["ru","en"], fallbackLng: "en",
react: { useSuspense: false },          // критично — нет <Suspense>
interpolation: { escapeValue: false },
returnEmptyString: false
```

`applyLang(lang)` — единая точка:
1. `i18n.changeLanguage(lang)`
2. `document.documentElement.lang = lang`
3. `PrimeReactProvider value={{ locale: lang }}` (ConfirmDialog accept/reject, DataTable filter)

Авто-язык: `navigator.language.startsWith("ru") → ru, else en` (без `i18next-browser-languagedetector` — проще при 3-режимной модели auto/ru/en).

`lib/format.ts` — вынести дубли `fmtBytes` (Dashboard/Requests/Cache), `fmtBucket`, `fmtUptime`, `fmtMs`; даты через `Intl.DateTimeFormat('ru-RU'|'en-US')` (сейчас hardcode `toLocaleDateString("ru-RU")` в Dashboard.tsx:57-58).

## Проверка

```bash
cd web && bun run lint && bun run build
```

Ручной smoke (`cd web && bun run dev`):
1. **FOUC**: hard-reload при OS dark — первый paint уже тёмный (и наоборот). С forced `localStorage.rustcache.theme`.
2. **Тема**: Settings + sidebar; `auto` реагирует на emulate `prefers-color-scheme`; reload сохраняет выбор.
3. **Язык**: Settings + sidebar; nav, заголовки, кнопки, toast, ConfirmDialog, emptyMessage, placeholders переключаются; `html lang` меняется; кнопки Yes/No в ConfirmDialog тоже (PrimeReact locale).
4. **Interpolation**: purge cache → «Удалено файлов: N» / «Purged files: N».
5. **Connect**: en — проза английская, `<Code>` с `netsh`/`export`/`curl` и правильными `ip:port`.
6. **Formatters**: `КБ`/`KB`, даты `ru-RU`/`en-US`, `мс`/`ms`.
7. **Charts**: в dark — светлый текст осей/легенды.
8. **embed-ui** (опционально): `cargo build -p rustcache --features embed-ui`, curl `/themes/lara-dark-indigo.css` → 200.

## Риски / готчи

| Риск | Митигация |
|---|---|
| CSS-var override → полутёмный UI | свап стилей (не override) |
| FOUC от hashed assets | стабильные `public/themes/*` + inline script |
| `tsc -b` падает на JSON import | `resolveJsonModule: true` |
| i18next Suspense сносит приложение | `react: { useSuspense: false }` |
| ConfirmDialog остаётся Yes/No | `addLocale` + `PrimeReactProvider locale` |
| Chart.js игнорирует CSS vars | `Chart.defaults.color`/`borderColor`; key на `resolvedTheme` |
| Module-level `items` в Layout не реагирует на lang | строить массив внутри компонента |
| Biome organizeImports | прогнать `bun run fmt` перед gate |
| `confirmDialog()`/`toast.show()` захватывают `t` на момент вызова | приемлемо (диалог не live-retranslate) |
| embed-ui + public/ | `rust-embed` берёт весь `web/dist` — проверить после build |
