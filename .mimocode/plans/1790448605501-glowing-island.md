# PAC/WPAD tabs + `[pac] preferred_ip`

## Goal

1. Redesign the Connect **PAC / WPAD** card with **5 tabs** (Windows / Linux / macOS / iOS / Android), same pattern as "Platform instructions" (`TabView`/`TabPanel`, `Step`, `Code`, `Trans`).
2. PAC/WPAD URLs and commands always use the **selected IP** on Connect (mostly already true; close picker gaps).
3. New config **`[pac] preferred_ip`**: when set, PAC body's proxy host **always** uses it (overrides Host header); Connect defaults selection to it. Empty = current behavior. **Hot-applied** (like `pac.mode`).

Order: backend first (schema → validate → PAC handlers), then UI (types → Settings → Connect + i18n).

---

## Phase 1 — Config schema + validation

### `crates/rustcache/src/config/schema.rs`
- `PacConfig`: add `#[serde(default = "default_pac_preferred_ip")] pub preferred_ip: String` with default `""`.
- Include in `impl Default for PacConfig`.
- Extend `pac_parse` test: explicit `preferred_ip = "10.0.0.5"` and omission → `""`.

### `config.example.toml` `[pac]`
```toml
# Host always embedded in the PAC body. Empty = automatic (request Host header,
# else best LAN IPv4). Non-empty overrides Host. Hot-applied.
preferred_ip = ""
```

### `crates/rustcache/src/config/validate.rs`
- **Do not** add `pac.preferred_ip` to `restart_fields_diff` (hot).
- Validate: empty/whitespace → OK. Else accept IP (`IpAddr`, optionally `[ipv6]` stored **without** brackets) or simple hostname (≤253, RFC-1123-ish labels). Reject scheme/port/path/spaces. On fail: `FieldIssue` `"pac.preferred_ip"`.

### Semantics

| Input | PAC `proxy_host` | Connect default |
|-------|------------------|-----------------|
| `""` | Host-header → `best_lan_ipv4()` (today) | current picker |
| IP / hostname | **always** that value (ignore Host) | select it; add to picker if missing |
| IPv6 | emit bracketed: `PROXY [::1]:3128` | same string |

- Unit test: IPv6 → `PROXY [::1]:3128`.

### `crates/rustcache/src/api/handlers/pac.rs`
- `resolve_proxy_host(host_header, preferred_ip)`: if preferred non-empty → return it (strip `[]`); else existing Host logic.
