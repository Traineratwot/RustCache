# RustCache — SOLID + Best-Practices Refactor

Full phased refactor of `rustcache-core`, `rustcache`, and `web/`. English purpose-focused docs on public API. Latent bugs fixed as we touch their code.

## Binding decisions

- **Scope:** full refactor, both Rust and React, in ordered shippable phases.
- **Bugs:** fix clear latent bugs and misleading APIs (register below). Pure refactor elsewhere.
- **Docs:** rustdoc `///` on every public Rust item; JSDoc on every exported React component/hook/helper. Purpose-focused (why / what invariant), English. Skip trivial private one-liners. No refactor-narrating comments.

## Non-negotiables (AGENTS.md)

No `unwrap`/`expect` outside tests · CA key 0600 · never log Authorization/Cookie/query secrets · hex-blake3 keys on every disk path (`is_hex_key`) · only GET populates cache (HEAD may read) · `Authorization` bypasses cache · API binds 127.0.0.1 · every config field manageable in Settings.tsx · `.gitignore` keeps `/cache/` and `/ca/` · no `parking_lot::Mutex` across `.await` · upstream TLS = webpki-roots only · Vary not in cache key (leave alone) · UI labels Russian, code comments English.

Gate before each phase is done:

```bash
cargo fmt --check && cargo clippy --workspace -- -D warnings && cargo test --workspace
# UI phases also:
npm --prefix web run lint && npm --prefix web run build
```

## Guiding rules

- Surgical extraction, never big-bang. Tree stays shippable after each phase.
- Follow the **code**, not `docs/plans/*` (drifted: stats/ring→SQLite logstore, moka→coalesce, Tailwind→styles.css).
- Existing integration tests pass **unchanged** unless a type/name physically moves (then mechanical update in the same commit).
- Docs policy applied inside every phase, not as a final afterthought.

## Design decisions

### Traits — minimal, free functions first

Do **not** trait-ify `OriginFetcher` / `DiskCache` / `LogStore`. Integration tests already use real types; traits would only add indirection. Use free functions + small value structs (`RequestContext`, `CacheOutcome`, `FieldIssue`). Optional later seam: `RequestLog` trait — defer.

### Shared serve path (http_proxy + mitm_proxy)

Free function + generic writer, not a trait:

```rust
// listeners/serve.rs
pub struct RequestContext { method, url, host, headers, started: Instant }
pub struct CacheOutcome { status, headers, body: Arc<[u8]>, outcome: Outcome, resp_bytes, keep_alive }
pub async fn resolve_cached(engine, ctx, tls: Option<Arc<TlsConnector>>) -> Result<CacheOutcome, ResolveError>;
pub fn revalidate_outcome(old: &CachedEntry, new: &CachedEntry) -> Outcome; // etag AND body
// listeners/wire.rs
pub async fn write_http_response<W: AsyncWriteExt + Unpin>(w, status, headers, body, close: bool) -> Result<()>;
pub async fn read_http_request<R: AsyncRead>(...) -> Result<HttpRequest>; // one 32 MB body cap
```

Revalidation rule unified: `HIT_REVALIDATED` iff etag equal **and** body equal (MITM currently compares body only). ReqRecord built once inside `resolve_cached` / `resolve_bypass`.

### `Outcome` enum (serde-stable)

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum Outcome {
    #[serde(rename = "HIT")] Hit,
    #[serde(rename = "HIT_REVALIDATED")] HitRevalidated,
    #[serde(rename = "REVALIDATED")] Revalidated,
    #[serde(rename = "MISS")] Miss,
    #[serde(rename = "BYPASS")] Bypass,
    #[serde(rename = "TUNNEL")] Tunnel,
    #[serde(rename = "ERROR")] Error,
    #[serde(rename = "REJECT_CMD")] RejectCmd,
}
impl Outcome {
    pub const ALL: [Outcome; 8];          // replaces CANONICAL_OUTCOMES
    pub fn as_str(self) -> &'static str;
    pub fn is_hit(self) -> bool;
    pub fn from_db_lossy(s: &str) -> Outcome;
}
```

JSON/SQL wire format unchanged (`"HIT"` etc.). DB stays TEXT; bind `as_str()`, read via `from_db_lossy`. UI mirrors in `web/src/lib/outcome.ts`.

### Config system

- `config/validate.rs`: `FieldIssue`, `validate_config`, port/dir probes.
- `config/persist.rs`: `write_config_toml(...) -> Result<()>` — never silent empty write.
- `Config::restart_fields_diff(&self, old: &Config) -> Vec<&'static str>` lives on schema.
- `schema.rs`: `#[derive(Default)]` + `#[serde(default = ...)]` only where non-trivial. Delete misleading `redacted()`.
- New config field touch-list: schema.rs, config.example.toml, validate.rs (if checked), web types.ts, Settings.tsx field block (+ constants if unit conversion). Settings.tsx stays by hard rule.

## Phases

### P1 — Baseline, dead code, local bugs
**SOLID:** SRP-lite, DRY, honest APIs.

- Modify: `cache/mem.rs` (B1), `cache/{disk,key,meta}.rs` (B14, B16), `excl/matchers.rs` (B12, drop swap), `certs/leaf.rs` (B13), `config/schema.rs` (B7), `config/watch.rs` (B11), `engine.rs` (B10, B9), `http_proxy.rs` (B8), `mitm_proxy.rs` (B2 minimal), `web/src/pages/{Requests,Health}.tsx` (B19).
- Create: `listeners/wire.rs` (request reading + `reason_phrase` only for now), `web/src/lib/constants.ts`.
- Delete: `certs/store.rs`, `SharedCoalesce`, `ExclusionSet::swap`.
- Verify: full Rust gate. New unit tests: mem TTL, IPv6 host parse. Integration tests **unchanged**.

### P2 — `Outcome` enum + logstore decomposition
**SOLID:** SRP (writer vs query vs analytics), OCP.

- Create: `stats/logstore/{mod,outcome,dto,writer,schema,query,analytics}.rs`.
- Modify: `stats/mod.rs` re-exports; all `outcome: "X".into()` → `Outcome::X` (http_proxy, mitm_proxy, socks5, engine); routes query params typed.
- Type changes: `ReqRecord.outcome: Outcome`, `LogQuery.outcome: Option<Outcome>`, `OutcomeStat.outcome: Outcome`. **JSON strings unchanged.**
- Verify: full gate; `api_requests` unchanged. Manual: `curl /api/requests` still shows `"outcome":"HIT"`.

### P3 — Shared wire + unified cache serve (heart of refactor)
**SOLID:** DRY, OCP (new listener reuses `resolve_cached`).

- Create: `listeners/serve.rs`; finish `listeners/wire.rs`.
- Modify: `http_proxy.rs` (CONNECT + dispatch only; delete `serve_cached`), `mitm_proxy.rs` (TLS/mint/splice only; delete clone), `socks5.rs` (Outcome for TUNNEL/REJECT_CMD).
- Move `cache_headers` / `entry_age_secs` to `wire.rs` (unit tests move with them).
- Bugs: B2, B3, B4, B20.
- Verify: full gate; **integration `proxy_cache`/`mitm`/`tunnel` unchanged**. New: `revalidate_outcome` matrix. `bash scripts/smoke.sh`.

### P4 — `CacheEngine` encapsulation
**SOLID:** SRP, Law of Demeter.

- Make `disk/mem/metrics/logs/exclusions/fetcher` **private**; narrow public methods (`lookup`, `fetch_and_store`, `record`, `purge_*`, `tls_connector()`, `logs()`, `metrics()`, …).
- Split `fetch_and_store` (105 lines) into `apply_revalidation` + `store_if_cacheable`.
- Mechanical call-site updates in `api/*`, `listeners/*`, `tests/common/mod.rs` if needed (prefer test-neutral surface).
- Verify: full gate; integration tests preferably unchanged.

### P5 — Config: schema, validation, persistence
**SOLID:** SRP (validation ≠ HTTP), DRY (one write path).

- Create: `config/validate.rs`, `config/persist.rs`.
- Modify: `schema.rs` (derive Default, `restart_fields_diff`, delete `redacted`, rustdoc every field), `watch.rs` (Arc get), `routes.rs` (drop validate_config + probes + toml writes).
- Bugs: B5, B7. `PUT /api/config` response shape unchanged.
- Verify: full gate; new unit tests: validate_config cases, `write_config_toml` failure leaves file intact.

### P6 — API handlers + startup
**SOLID:** SRP (one handler file = one resource), thin main.

- Create: `api/error.rs` (replaces 8× error JSON), `api/handlers/*.rs`, `startup.rs`.
- Modify: `routes.rs` → `router()` only; `state.rs` narrow; `main.rs` `run()` thinned via `startup::build_and_bind`.
- Verify: full gate; `api_pac`/`api_requests` unchanged. Smoke: bad `PUT /api/config` → `errors[]`.

### P7 — React foundations
**SOLID:** SRP (hooks own data lifecycle), DRY, DIP (ErrorBoundary).

- Create: `hooks/{useApi,usePolling,useToast,useDebounced}.ts`, `components/ErrorBoundary.tsx`, `lib/{outcome,paths}.ts`, `api/errors.ts`.
- Modify: `api/client.ts` (uniform ApiError; move `caFingerprint` to `lib/crypto.ts`), all pages onto hooks, `lib/format.ts` pure (no i18n singleton), slim `index.html` FOUC, delete `web/.oxlintrc.json`, **`tsconfig` → `"strict": true`** (own commit, fix fallout immediately).
- Bugs: B18, outcomeSeverity dedup.
- Verify: `npm --prefix web run lint && npm --prefix web run build` after each sub-step.

### P8 — Settings split + UI polish + docs sweep
**SOLID:** SRP (form vs fields vs sections), OCP (new config field = one field block).

- Create: `hooks/useConfigForm.ts`, `components/settings/fields.tsx`, optional `sections/{Network,Cache,Logs,Ca,Pac}.tsx` if Settings still > ~250 lines.
- Modify: `Settings.tsx` composition; magic numbers → `lib/constants.ts`; `patch()` per-field errors (B17); `Requests.tsx` debounce + loading + drop `void reloadTick`; `Dashboard.tsx` `useMemo` charts; `Connect.tsx` + `Health.tsx` share `lib/net.ts` ports/docker detect; remaining hardcoded strings → i18n (B19 sweep).
- Docs sweep: rustdoc on every pub item both crates; JSDoc on every exported component/hook/helper; real `README.md`; `docs/plans/*` marked superseded (do not rewrite Russian plans).
- Verify: full Rust gate + web lint/build + manual Settings save/reload/restart walk + `bash scripts/smoke.sh`.

## Documentation policy (every phase)

- [ ] Every `pub` item has `///` stating why it exists / which invariant it protects (not a name restatement).
- [ ] Hidden invariants on public fields documented (outcome wire stability, CA key 0600, hex-key disk paths).
- [ ] JSDoc on every exported React component/hook/helper.
- [ ] No refactor-narrating comments (“extracted from X”). Current design only.
- [ ] New modules start with `//!` (responsibility + what belongs here vs neighbors).
- [ ] Hard-rule invariants restated at enforcement site (`is_hex_key`, auth bypass).
- [ ] UI strings in `i18n/locales/{ru,en}.json`; code comments English.

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| P3 changes revalidation metrics (B3) | Shared `revalidate_outcome` + unit matrix; call out in commit notes |
| MITM body-cap (B2) rejects huge request bodies | Same cap as HTTP path; 32 MB is generous |
| P4 breaks fixtures via private fields | Keep `SharedEngine` method surface sufficient; mechanical `common/mod.rs` update same commit |
| B5 surfaces TOML failure as 500 | Desired; unit test: failure leaves old file intact |
| Strict TS flood in P7 | Own commit; fix fallout immediately; no `any` escapes |
| Dual lockfiles / `.oxlintrc.json` | Delete oxlint config in P7; verify which lockfile is actually used before dropping |
| Large unreviewable diffs | One phase per unit of work; list bug IDs closed at each gate |
| Flaky `free_port` / wall-clock asserts | Do not tighten timing; prefer retry over sleep |
