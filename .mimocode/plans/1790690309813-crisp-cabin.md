# RustCache Client — кроссплатформенный desktop-клиент

## Цель

Маленький надёжный клиент (Windows / Linux / macOS, без телефонов), который:

1. Сам ставит/снимает root CA RustCache в trust store ОС
2. Поднимает локальный прокси и направляет «весь интернет» машины на себя (system proxy; TUN — позже, опционально)
3. Форвардит трафик в уже запущенный RustCache (кэш + MITM)
4. При недоступности/ошибке RustCache уходит в **DIRECT** (fail-open)
5. CLI обязателен; простой GUI (tray + окно) — второй фазой

Клиент **не** запускает и не останавливает процесс `rustcache` — только подключается.

## Архитектура (один подход)

| Решение | Выбор |
|---|---|
| Язык | Rust, тот же workspace, edition 2024 |
| Crate | `crates/rustcache-client` (новый member) |
| Binary | `rustcache-client` |
| Захват (MVP) | system proxy → локальный устойчивый HTTP-proxy `127.0.0.1:31280` |
| Захват (P3) | опциональный TUN (wintun / utun / tun + netstack) |
| Связь с RustCache | HTTP proxy protocol: plain → `:3128`, CONNECT/HTTPS → `:3129` (MITM) |
| Failover | circuit breaker, fail-open DIRECT |
| GUI (P2) | `tray-icon` + `eframe`/`egui` |
| TLS у клиента | **не** терминируется — только TCP-splice после `CONNECT 200` |

Почему system proxy, а не TUN в MVP: без драйверов и elevation, полностью обратимо, покрывает браузеры и большинство приложений. TUN — только для apps, игнорирующих system proxy.

Почему `:3129` для CONNECT: `:3128` CONNECT — raw tunnel без кэша; `:3129` после CONNECT делает rustls MITM с leaf-сертификатом → HTTPS кэшируется. Клиент после `200` просто splice'ит байты.

## Локальный resilient proxy

**Bind:** `127.0.0.1:31280` (конфиг; не пересекается с 3128/3129/1080/8080). Занят порт → exit 5, без «тихой» подмены.

На соединение (deadline на первые байты, как `HANDSHAKE_TIMEOUT`):

1. Парсим только request-line + нужные headers.
2. `CONNECT host:port`:
   - **Mitm** → TCP `:3129`, отправить CONNECT, дождаться `200`, ответить клиенту `200`, `copy_bidirectional` (raw splice; RustCache отдаёт MITM leaf).
   - **RawTunnel** → то же против `:3128` (excluded hosts, без кэша).
   - **Direct** → TCP к `host:port`, `200`, splice.
3. Plain HTTP (`GET http://…`):
   - Up → TCP `:3128`, forward as-is (absolute-URI — валидная proxy-форма), splice.
   - Direct → connect origin `:80`, request-line → origin-form, убрать hop-by-hop (`Proxy-Connection`, `Proxy-Authorization`), splice.

Тел не буферизуем. Established tunnel без timeout. In-flight splice **не** рвём при смене состояния breaker'а.

### Circuit breaker (`health.rs`)

- Poll **2 s**: `GET /api/health` (timeout 500 ms) → `ok` + `listeners[].running` (HTTP / HTTPS).
- Backup: TCP-probe `:3128`/`:3129`, если API не отвечает.
- `Closed` → `Open` после **3** подряд фейлов или `running=false` нужного listener'а → `HalfOpen` через **5 s** (одна пробная; успех закрывает).
- Решение — только на accept. Цель: p95 переключения нового соединения ≤ 2 s + 1 RTT.

### Routing

| Условие | CONNECT | HTTP |
|---|---|---|
| Closed, не excluded | Mitm `:3129` | `:3128` |
| Closed, excluded | RawTunnel `:3128` | Direct |
| Open / Degraded | Direct | Direct |

Excluded hosts — best-effort из `GET /api/exclusions` (пусто при ошибке). Если HTTPS listener `running=false` → CONNECT сразу Direct (не в чёрную дыру).

## CA install (`ca/`)

**Fetch:** `GET /api/ca.crt` (PEM) → fallback `--ca-file` / `$data_dir/ca/ca.crt`. SHA-256 fingerprint; если уже установлен тот же — skip.

| ОС | Install | Uninstall | Elevation |
|---|---|---|---|
| Windows | `certutil -user -addstore "Root" ca.crt` (machine: без `-user`) | `certutil -user -delstore "Root" <SHA1>` | user: нет; machine: admin |
| macOS | `security add-trusted-cert -d -r trustRoot -k ~/Library/Keychains/login.keychain-db ca.crt` (system: System.keychain) | `security delete-certificate -Z <SHA1> <keychain>` | system: admin |
| Linux system | copy `/usr/local/share/ca-certificates/rustcache-ca.crt` + `update-ca-certificates` | delete + `update-ca-certificates --fresh` | root |
| Linux NSS (Firefox) | `certutil -A -n "RustCache" -t "C,," -i ca.crt -d sql:$HOME/.pki/nssdb` + firefox profiles | `certutil -D -n "RustCache"` | user |

`ca install` — user-level по умолчанию; `--system` — явно и с elevation. `ca status` — fingerprint match.

## System proxy (`sysproxy/`)

**Всегда** сначала snapshot в `$data_dir/client/proxy-restore.json` + `dirty=true`, потом apply, на чистом restore — снять dirty. При старте, если dirty → восстановить прежние настройки (crash recovery), затем apply.

| ОС | Apply | Restore |
|---|---|---|
| Windows | HKCU `…\Internet Settings`: `ProxyEnable=1`, `ProxyServer=http=127.0.0.1:31280;https=127.0.0.1:31280`, `ProxyOverride=<local>;…` + `InternetSetOption` refresh (`windows` crate) | записать сохранённые значения + refresh |
| macOS | `networksetup` per service: `-setwebproxy` / `-setsecurewebproxy` / `-setwebproxystate on` / `-setproxybypassdomains` | inverse |
| Linux | GNOME `gsettings set org.gnome.system.proxy …` (mode manual, host/port, ignore-hosts) | вернуть сохранённые значения / mode `'none'` |

Signals: SIGINT/SIGTERM (+ Windows ctrl) → `capture.disable()` + restore. Dirty-flag — safety net при crash.

**Обязательный bypass:** `127.0.0.1`, `localhost`, listen-port, `*.local` — чтобы не было proxy-loop.

Для CLI-приложений документируем `http_proxy`/`https_proxy` (env не ловит «весь интернет»).

## TUN (Phase 3, опционально)

- Windows: `wintun` + `netstack-smoltcp`, route `0.0.0.0/1`, admin
- Linux: `tun` (`/dev/net/tun`, CAP_NET_ADMIN) + smoltcp
- macOS: utun best-effort (полный capture — Network Extension, entitlements)
- MVP-slice TUN: TCP-only; DNS/UDP позже
- Только TUN требует elevation

## GUI (Phase 2)

- Tray (`tray-icon`): цвет = up/down/circuit; menu Capture On/Off, Mode, CA install, Settings, Quit (restore)
- Window (`eframe`/`egui`): status listeners + circuit, mode, CA fingerprint, upstream URL, optional `/api/stats`
- Тот же lib API, что и CLI. `run --tray` — proxy + tray в одном процессе

## Config + CLI

`~/.config/rustcache/client.toml` (Windows: `%APPDATA%\rustcache\client.toml`):

```toml
rustcache_api = "http://127.0.0.1:8080"
listen = "127.0.0.1:31280"
mode = "system"          # off | system | tun(p3)
fail_open = true
health_interval_ms = 2000
breaker_failures = 3
breaker_open_ms = 5000
proxy_bypass = ["localhost", "127.0.0.1", "*.local"]
ca = { source = "api", file = "", scope = "user" }
log = { level = "info", file = "" }
```

```
rustcache-client run [--mode off|system|tun] [--no-tray] [--config P]
rustcache-client ca install|uninstall|status [--system] [--ca-file P]
rustcache-client proxy on|off|status
rustcache-client status
rustcache-client doctor
rustcache-client config init|path|show
```

Exit codes: `0` ok · `1` generic · `2` config · `3` elevation · `4` RustCache unreachable · `5` platform op failed.

Logging: tracing → stderr, `RUST_LOG` / `log.level`. Не логировать секреты в query и CA key.

## Фейл-кейсы

| Случай | Поведение |
|---|---|
| RustCache упал | breaker ≤ ~2 s; новые conns DIRECT; in-flight живут |
| MITM listener down | CONNECT → Direct |
| CA не установлен | HTTPS в браузере сломается; `run` warn once; **не** auto-install |
| Crash при включённом proxy | dirty snapshot → restore на старте |
| Multi-user | user-level по умолчанию; `--system` явно |
| VPN | bypass localhost; TUN может конфликтовать с route VPN — документировать |
| Порт занят | exit 5 |

## Verification

1. **Unit:** `http_parse`, матрица `route` (up/down/excluded × method), `CircuitBreaker` (fake clock).
2. **Integration:** mock RustCache (hyper) на ephemeral ports (`/api/health`, `/api/ca.crt`, CONNECT sink); `ProxyServer` на `127.0.0.1:0`; assert: HTTP forward; kill mock → DIRECT; in-flight переживает kill; breaker recover.
3. **Sysproxy/CA:** `--dry-run` печатает точные команды/registry-записи (snapshot-тесты строк). Manual: install/uninstall CA (Firefox+Chrome), set/restore (`gsettings get` / `reg query` / `networksetup -getwebproxy`), `kill -9` → dirty recovery.
4. **Smoke:** `scripts/smoke-client.sh` — curl через `-x 127.0.0.1:31280` HIT/MISS; stop rustcache → curl DIRECT ok; restart → circuit closes.
5. **Gate:** `cargo fmt --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace` (и `-p rustcache-client`).

## Risks

- macOS `networksetup` может просить admin / SIP — `SysProxy` abstract, non-zero → exit 5
- Linux DE diversity (GNOME в MVP) — `doctor` объясняет, если ничего не применилось
- Apps, игнорирующие system proxy — вне MVP; ответ = TUN
- Proxy-loop — всегда bypass loopback
- HPKI/pin в браузерах — exclusions → Direct
