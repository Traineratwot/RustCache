# PAC — URL автоматической настройки прокси

**Feature:** serve `proxy.pac` / `wpad.dat` (Proxy Auto-Config) + UI on Connect page.

**User choices:** PAC on the API stack · configurable `FindProxyForURL` mode (`http` | `socks` | `http+socks`) · exclusions (domains+CIDR) → `DIRECT` · both `/proxy.pac` and `/wpad.dat`.

## Approach

Axum routes on the existing API router **plus** an optional dedicated LAN listener that serves **only** the two PAC paths.

| Surface | Bind (default) | Routes | Why |
|---|---|---|---|
| Admin API | `127.0.0.1:8080` (unchanged) | `/proxy.pac`, `/wpad.dat`, `/api/pac` + existing | local curl / UI |
| PAC listener | `0.0.0.0:8081` (`pac.bind`) | `/proxy.pac`, `/wpad.dat` only | LAN clients fetch PAC **without** exposing purge/config/exclusions |

Why not `api.bind=0.0.0.0:8080`: would expose admin endpoints to LAN (AGENTS.md security rule). Why not :3128: that is the proxy protocol port, and the request was "on the API".

PAC body is generated **per request** from `LiveConfig` + `engine.exclusions` — hot-reload of exclusions/mode needs no restart. `pac.bind` / `enabled` / proxy ports need restart (same as today).

## Config (`config/schema.rs` + `config.example.toml`)

```rust
#[derive(Debug, Clone, Copy, Serialize, Deserialize, Default, PartialEq, Eq)]
pub enum PacMode {
    Http,
    Socks,
    #[default]
    #[serde(rename = "http+socks")]
    HttpSocks,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PacConfig {
    pub enabled: bool,   // default true
    pub bind: String,    // default "0.0.0.0:8081"
    pub mode: PacMode,   // default HttpSocks
}
// Config += #[serde(default)] pub pac: PacConfig
```

```toml
[pac]
enabled = true
bind = "0.0.0.0:8081"
mode = "http+socks"   # "http" | "socks" | "http+socks"
```

## PAC generation (`crates/rustcache/src/api/pac.rs` — new, pure)

```rust
pub struct PacParams<'a> {
    pub proxy_host: &'a str,
    pub http_port: u16,
    pub socks_port: u16,
    pub mode: PacMode,
    pub matchers: &'a [Matcher],
}
pub fn generate_pac(p: &PacParams<'_>) -> String;
fn cidr_to_netmask(cidr: &str) -> Option<String>; // "10.0.0.0/8" → "255.0.0.0", IPv6 → None
```

JS semantics must mirror `rustcache-core/src/excl/matchers.rs` exactly:

| Matcher | JS |
|---|---|
| `Exact{v}` | `host === "v"` |
| `Wildcard{v}` (`*.v`, apex **not** matched) | `shExpMatch(host, "*.v")` |
| `Suffix{v}` (`.v`, apex matched) | `host === "v" \|\| dnsDomainIs(host, ".v")` |
| `Cidr{v}` (IPv4 only) | `isInNet(dnsResolve(host), "net", "mask")` — skip IPv6 |

Return string (`h` = proxy host):
- `http` → `PROXY h:{http_port}; DIRECT`
- `socks` → `SOCKS5 h:{socks_port}; DIRECT`
- `http+socks` → `PROXY h:{http_port}; SOCKS5 h:{socks_port}; DIRECT`

Body prefix always: `isPlainHostName(host)` → `DIRECT`.

**proxy_host:** request `Host` header host-part (no port). If missing / `localhost` / loopback → best LAN IPv4 (same sort as `netinfo` in `routes.rs:223-248`, extract shared helper `best_lan_ipv4()`).

Headers: `Content-Type: application/x-ns-proxy-autoconfig`, `Cache-Control: no-store, no-cache, must-revalidate`, `Pragma: no-cache`. No `unwrap`/`expect` outside tests.

## API surface

- `GET /proxy.pac` / `GET /wpad.dat` — PAC body (admin router + PAC listener)
- `GET /api/pac` — `{ enabled, mode, bind, port, urls: ["http://<ip>:8081/proxy.pac", …] }` for the UI

## UI (`Connect.tsx`, Russian)

New card after IP selector:
- PAC URL for the selected IP: `http://{ip}:{pacPort}/proxy.pac` + copy button (existing toast pattern)
- Short steps: Windows → «Автоматическая настройка прокси» / script URL; Linux (Firefox) → «URL автоматической настройки прокси»; Android → Wi-Fi → Proxy → Auto-config
- Note: excluded hosts → DIRECT; mode shown; `http_proxy` env is **not** PAC (browser-level)

## Implementation order

1. Config: `PacMode`/`PacConfig` + example.toml + schema tests
2. `api/pac.rs` generator + unit tests (modes, matchers, cidr masks, empty exclusions)
3. Routes `proxy_pac` + `pac_info`; shared `best_lan_ipv4`
4. `main.rs` PAC-only listener
5. Web: types, client, Connect card
6. Optional `tests/api_pac.rs`; run gate

## Verification

```bash
cargo fmt --check && cargo clippy --workspace -- -D warnings && cargo test --workspace

cargo run -p rustcache -- run --config config.toml
curl -sD- http://127.0.0.1:8080/proxy.pac
curl -sD- http://127.0.0.1:8080/wpad.dat          # identical body
curl -s  http://127.0.0.1:8081/proxy.pac           # LAN PAC listener
curl -s  http://127.0.0.1:8080/api/pac
```

Expect: `application/x-ns-proxy-autoconfig`, `no-store`, `FindProxyForURL`, proxy host = request Host (or LAN fallback), exclusion rules present when configured.

Unit tests (`api/pac.rs`): each mode string; Exact/Wildcard/Suffix (Wildcard does not match apex); `cidr_to_netmask` `/0` `/8` `/16` `/24` `/32`; IPv6 CIDR omitted.

Manual: browser auto-config URL `http://<lan-ip>:8081/proxy.pac`, visit excluded host (DIRECT) vs normal (via proxy); change `mode`/exclusions + reload → refetch PAC.

## Out of scope

WPAD via DNS/DHCP · HTTPS PAC · PAC auth · IPv6 `isInNet` · caching PAC body · exposing admin API off localhost.
