# RustCache: GitHub Actions release + deb repo на Pages

## Цель

Push в `main`, изменяющий версию в `Cargo.toml` → GitHub Release (`.deb` + `tar.gz` + SHA256SUMS) + обновление публичного apt-репозитория на GitHub Pages. Архитектуры: **amd64** и **arm64**.

Решения пользователя:
- Ветка-триггер: **`main`** (не master)
- Источник версии: **только `Cargo.toml`** (`[workspace.package] version`) — файл `version.build` **не заводим**
- Pages: **публичный** apt-репо (`deb [trusted=yes]`)
- Релиз: `.deb` (обе архитектуры) + `tar.gz` бинарника + `SHA256SUMS`

## Контекст (из исследования)

- Бинарник: `rustcache` (`crates/rustcache`), фича **`embed-ui` обязательна** (SPA вшивается в бинарь; `web/dist` должен существировать до `cargo build`).
- Сборка: `npm --prefix web install && npm --prefix web run build && cargo build --release --features embed-ui`.
- Никакой существующей упаковки: нет `.github/`, `debian/`, systemd-юнитов, тегов, релизов — всё с нуля.
- CLI: `rustcache [--data-dir DIR] run --config PATH`; `--config` по умолчанию CWD-относительный → в юните обязателен абсолютный путь.
- Данные: `/var/lib/rustcache` (CA создаётся сам, `ca.key` 0600; `logs.db` 0600). Логи → stdout/stderr → journald.
- Порты >1024 → root/`CAP_NET_BIND_SERVICE` не нужны.
- Self-restart (`POST /api/config/restart`) завершает родителя с exit 0 → в юните `Restart=on-failure` (не `always`).
- `paths:` в GHA не умеет следить за содержимым — реальный гейт: **тег `vX.Y.Z` ещё не существует**.

## 1. `packaging/` — deb + systemd

### Устанавливаемое дерево

| Путь | Режим | Примечание |
|------|-------|------------|
| `/usr/bin/rustcache` | 0755 | release-бинарь с `embed-ui` |
| `/etc/rustcache/config.toml` | 0644 | **conffile**, из `config.system.toml` с `data_dir = "/var/lib/rustcache"` |
| `/usr/lib/systemd/system/rustcache.service` | 0644 | |
| `/var/lib/rustcache/` | dir | пустой, `chown` в postinst |
| `/usr/share/doc/rustcache/copyright` | 0644 | MIT |

### `packaging/debian/control.in`

```
Package: rustcache
Version: @VERSION@
Section: net
Priority: optional
Architecture: @ARCH@
Maintainer: Traineratwot <Traineratwot@users.noreply.github.com>
Homepage: https://github.com/Traineratwot/RustCache
Depends: libc6, libgcc-s1
Description: Caching HTTP/HTTPS proxy with MITM and disk cache
 ...
```

`Installed-Size` дописывает `build-deb.sh`. `Depends` проверить один раз `ldd target/release/rustcache` (ожидается только glibc/libgcc — OpenSSL не используется).

### `packaging/systemd/rustcache.service` (суть)

```ini
[Service]
Type=simple
User=rustcache
Group=rustcache
WorkingDirectory=/var/lib/rustcache
ExecStart=/usr/bin/rustcache run --config /etc/rustcache/config.toml
Restart=on-failure          # self-restart из UI выходит с 0 — не always
RestartSec=2s
NoNewPrivileges=true
ProtectSystem=strict
ReadWritePaths=/var/lib/rustcache
```

### Maintainer scripts (`#!/bin/sh`, `set -e`)

- **postinst** (`configure`): создать system-user `rustcache` (`getent` + `adduser --system --group`), `install -d -o rustcache -g rustcache -m 0750 /var/lib/rustcache`, `deb-systemd-helper enable`, `daemon-reload`, `deb-systemd-invoke start` (на upgrade — `try-restart`). Гвард `[ -d /run/systemd/system ]`.
- **prerm** (`remove`): `deb-systemd-invoke stop` (на `upgrade` — не останавливать).
- **postrm**: `remove` → `daemon-reload`; `purge` → `rm -rf /var/lib/rustcache` (юзера не удаляем).
- **conffiles**: `/etc/rustcache/config.toml`.

### `packaging/scripts/build-deb.sh VERSION ARCH`

Собирает stage-дерево, подставляет `@VERSION@`/`@ARCH@` в control, `dpkg-deb --root-owner-group --build` → `dist/rustcache_${VERSION}_${ARCH}.deb`. Идемпотентный, `mkdir -p dist`.

## 2. `.github/workflows/release.yml`

### Trigger

```yaml
on:
  push:
    branches: [main]
    paths: ['Cargo.toml']    # единственное место версии
  workflow_dispatch:         # bootstrap / повторный запуск
concurrency:
  group: release-${{ github.ref }}
  cancel-in-progress: false
permissions:
  contents: read
```

### Jobs

```
version ──► gate ──► build (matrix amd64/arm64) ──┬──► release
                                                  └──► apt-repo
```

**`version`** — вытягивает `[workspace.package].version` через `python3 -c "import tomllib; ..."`, кладёт `version=0.1.0`, `tag=v0.1.0`. Далее `git ls-remote --tags origin refs/tags/vX.Y.Z`: если тег есть → `should_release=false`, все последующие jobs пропускаются. Outputs: `version`, `tag`, `should_release`.

**`gate`** — `uses: ./.github/workflows/ci.yml` (workflow_call), чтобы не дублировать quality-шаги.

**`build`** (matrix, `fail-fast: false`):
- `ubuntu-22.04` → `deb_arch: amd64`
- `ubuntu-22.04-arm` → `deb_arch: arm64` (fallback при отсутствии: `cross` + `aarch64-unknown-linux-gnu`; native предпочтительнее)
- Шаги: checkout → `dtolnay/rust-toolchain@stable` → `actions/setup-node@v4` (node 22) → npm web install+build → `cargo build --release --features embed-ui` → `./packaging/scripts/build-deb.sh $VERSION $ARCH` → tar.gz (`rustcache_$VERSION_linux_$ARCH.tar.gz` c бинарём + `config.example.toml`) → `upload-artifact` (`release-$ARCH`).

Runners **22.04**, а не `ubuntu-latest`: glibc 2.35 вместо ≥2.39 — иначе пакет не встанет на Debian bookworm.

**`release`** (`contents: write`):
1. `download-artifact` → `dist/`
2. `sha256sum *.deb *.tar.gz > SHA256SUMS`
3. `gh release create "$TAG" --target "$GITHUB_SHA" --title "$TAG" --generate-notes dist/*.deb dist/*.tar.gz dist/SHA256SUMS` (`GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`) — создаёт тег + Release атомарно.

**`apt-repo`** (`contents: write`, `concurrency: gh-pages`, `cancel-in-progress: false`):
1. Скачать оба артефакта, `mkdir -p site/pool`, положить новые `.deb`.
2. **Слить** с предыдущим контентом: `git clone --depth 1 --branch gh-pages` (или orphan init при первом запуске) → `pool/` копит все версии.
3. `dpkg-scanpackages --multiversion pool /dev/null > Packages && gzip -9c Packages > Packages.gz` (+ опциональный `Release`).
4. Commit + push в `gh-pages` (bot identity).

**Почему git-push в `gh-pages`, а не `actions/deploy-pages`:** Pages-артефакты *заменяют* сайт целиком; apt-репо должно **накапливать** версии. Ветка `gh-pages` = durable store; `Packages.gz` всегда пересобирается по всему `pool/`. Одноразовая ручная настройка: Settings → Pages → Deploy from branch → `gh-pages` / root.

Итоговая строка для пользователя:
```
deb [trusted=yes] https://traineratwot.github.io/RustCache/ ./
```

## 5. Проверка

**Локально (упаковка):**
```bash
npm --prefix web install && npm --prefix web run build
cargo build --release --features embed-ui
./packaging/scripts/build-deb.sh 0.1.0 amd64
dpkg-deb --info dist/rustcache_0.1.0_amd64.deb
dpkg-deb --contents dist/rustcache_0.1.0_amd64.deb
```

**Локально (apt-индекс):** `dpkg-scanpackages --multiversion pool /dev/null` + `python3 -m http.server` + `apt-get install` из контейнера.

**В CI:**
1. Смержить workflows → `workflow_dispatch` → есть Release `v0.1.0` и `gh-pages` с `pool/` + `Packages.gz`.
2. Поднять версию до `0.1.1` в `Cargo.toml` → push → полный пайплайн, `v0.1.1` в Pages, старый deb **сохранился**.
3. Коммит, трогающий `Cargo.toml` без смены версии → `should_release=false`, jobs skipped.

**Приёмка (пользователь):**
```bash
echo "deb [trusted=yes] https://traineratwot.github.io/RustCache/ ./" \
  | sudo tee /etc/apt/sources.list.d/rustcache.list
sudo apt update && sudo apt install rustcache
systemctl status rustcache --no-pager
curl -x http://127.0.0.1:3128 http://example.com/   # дважды: MISS → HIT
```

## 6. Edge cases (принятые решения)

| Случай | Поведение |
|--------|-----------|
| Повторный запуск / тот же version | тег `vX.Y.Z` уже есть → skip |
| `Cargo.toml` без bump версии | skip (тот же гейт) |
| Первый запуск | `workflow_dispatch` (paths-фильтр не сработает на добавление workflow-файла) |
| Concurrent release | `concurrency: release-*` + `gh-pages` сериализуют |
| UI self-restart | `Restart=on-failure` + exit 0 → после restart из UI может потребоваться `systemctl start rustcache` (задокументировать; `exec` вместо spawn — follow-up в коде) |
| Нет `ubuntu-22.04-arm` | fallback: `cross build --target aarch64-unknown-linux-gnu` |
| glibc floor | сборка на 22.04 → Ubuntu 22.04+ / Debian 12+ |
| Размер Pages | ~10 МБ × 2 arch × N версий; при желании позже — retention |

## Gate перед «готово»

- `bash packaging/scripts/build-deb.sh` локально отрабатывает, `dpkg-deb --info/--contents` выглядят корректно
- `cargo fmt --check && cargo clippy --workspace -- -D warnings && cargo test --workspace` (не ломаем)
- YAML workflows валиден (actionlint при наличии / ревью глазами)
