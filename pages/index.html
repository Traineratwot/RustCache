RustCache

Caching HTTP/HTTPS proxy with MITM, disk cache, SOCKS5 and web UI.

Install (Debian / Ubuntu)

echo "deb [trusted=yes] https://traineratwot.github.io/RustCache/ ./" \
  | sudo tee /etc/apt/sources.list.d/rustcache.list
sudo apt update
sudo apt install rustcache

After install:

sudo systemctl status rustcache
# config:  /etc/rustcache/config.toml
# data:    /var/lib/rustcache
# logs:    journalctl -u rustcache
# web UI:  http://127.0.0.1:8080
