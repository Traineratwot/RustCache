RustCache

Caching HTTP/HTTPS proxy with MITM, disk cache, SOCKS5 and web UI.

Install (Debian / Ubuntu)

echo "deb [trusted=yes] https://traineratwot.github.io/RustCache/ ./" \
  | sudo tee /etc/apt/sources.list.d/rustcache.list
sudo apt update
sudo apt install rustcache rustcache-client

Server

Caching proxy daemon — HTTP/HTTPS MITM, disk cache, SOCKS5, web UI.

Docker

docker run -d --name rustcache \
  -p 3128:3128 -p 3129:3129 -p 1080:1080 \
  -p 8080:8080 -p 8081:8081 \
  -v rustcache-data:/var/lib/rustcache \
  ghcr.io/traineratwot/rustcache:latest

Web UI: http://127.0.0.1:8080 · Image: ghcr.io/traineratwot/rustcache

After install

sudo systemctl status rustcache
# config:  /etc/rustcache/config.toml
# data:    /var/lib/rustcache
# logs:    journalctl -u rustcache

Client

Desktop client — CA install, system proxy, resilient local proxy, status GUI.

Quick start

rustcache-client gui                 # status window
rustcache-client run --mode system   # proxy + system capture
rustcache-client ca install          # install root CA
rustcache-client proxy on|off        # system proxy
rustcache-client doctor              # diagnostics

Enter the RustCache host/IP in the GUI and press Connect — proxy ports are discovered via GET /api/health.
